User accounts will follow a consistent First.Last naming pattern for the User Principal Name (UPN) across all 15 users. The UPN will use the user’s first and last name, with the first letter of each name capitalized and the remaining letters in lowercase, separated by a period. For example, John Smith would use John.Smith@yourtenant.onmicrosoft.com. Security groups will follow the SEC-<Type>-<Name> naming pattern. SEC identifies the group as a security group, <Type> says what dimension you are slicing on, such as Dept for department, Role for job role, or Loc for location, and <Name> identifies the specific value. Examples include SEC-Dept-Finance, SEC-Dept-Sales, and SEC-Role-Helpdesk.

This convention provides a consistent and predictable naming structure that makes users and groups easier to identify and manage. Using the same UPN pattern for every user reduces confusion and makes account administration more consistent, while the security group pattern clearly communicates the purpose and scope of each group without having to inspect additional properties. This will also make the environment easier to maintain and scale as Northwind Services adds more users, departments, roles, or locations.

Design supports the IAM principles of: Consistency → Manageability → RBAC → Least Privilege → Governance → Automation → Scalability
